# 🎧 声音仓库 Audio Vault

> 一个可视化的个人音频资产库。指定一个文件夹当仓库，把音频丢进去，它会自动认出名字和创作者；你随手粘贴一段文字，它能把名称、类型、创作者、来源、可商用范围填得七七八八；鼠标停在波形上就能立刻试听。

**零第三方依赖** —— 后端只用 Python 标准库，前端是原生 HTML/CSS/JS。不做云端同步，不联网，所有数据都在你自己的硬盘上。

## ✨ 功能一览

| 功能 | 说明 |
| --- | --- |
| 自定义储存路径 | 首次启动指定，随时可改；支持目录浏览器逐层挑选 |
| 五个核心字段 | 音频名称、音频类型、创作者、来源、可商用范围（另含专辑、标签、备注、收藏） |
| 粘贴文字自动识别 | 认得 `名称：xxx` 这类标签，也认得 `周杰伦 - 晴天` 这种裸格式；自动嗅探素材站与授权关键词 |
| 文件自动提取信息 | 手写解析 ID3v2 / Vorbis Comment / MP4 ilst / OGG 标签 / WAV INFO；标签缺失时从文件名反推 |
| 悬停即播 | 鼠标停在音频条最前面的波形上，播放键浮现，按下即播；行内进度条 + 底部大波形进度条（可拖动定位） |
| 分类仓库 | 自由新建 / 改名 / 删除。**仓库就是真实子文件夹**，支持拖拽搬家 |
| 商用范围色标 | 绿＝可商用，琥珀＝需署名，红＝仅限非商用，灰＝待填 |
| 仅记录条目 | 没有本地文件也能先登记一条文字信息 |

## 🚀 快速开始

### 方式一：直接跑 exe（推荐给不想装环境的朋友）

1. 下载 `AudioVault.exe`
2. 双击运行，会弹出一个黑色命令行窗口并自动打开浏览器
3. 在页面里指定一个储存路径，开始使用
4. **用完想停**：关掉那个黑色窗口即可

> 首次运行若被杀毒软件拦截，选择「允许运行」即可（这是 PyInstaller 打包工具的常见误报）。

### 方式二：用 Python 源码运行

需要 **Python 3.8+**（无需安装任何第三方库）。

```bash
python server.py
```

Windows 用户也可以直接双击 `启动服务.bat`。

服务默认跑在 `http://127.0.0.1:8756/`，端口被占用会自动顺延（8757、8758…），实际地址看命令行窗口里的提示。

## 📖 使用教程

### 第 1 步：指定你的仓库位置

第一次打开会看到一张路径设置卡：

- **手动填写**：直接输入路径，比如 `F:\我的音频仓库`
- **点「浏览…」**：逐级展开文件夹挑一个
- **点盘符快捷按钮**：从 `C:` `D:` `F:` 等根目录开始找

设好后，顶栏中间会显示当前路径胶囊，**随时点它就能换仓库**。

> 换路径不会删除任何东西。旧路径的记录留在原地，切回来还在。

### 第 2 步：建立你的分类仓库

左侧栏就是「分类仓库」区，点右上角的 **＋** 新建，例如：

```
常用音效 / 项目BGM / 环境氛围 / 待确认版权
```

每个仓库对应储存路径下的**一个真实文件夹**。这带来三个好处：

- 用系统文件管理器打开，结构和程序里一模一样
- 仓库改名，文件夹跟着改名
- 想备份，整个文件夹复制走就行

仓库右边的小菜单里有「改名」和「删除」。删除时默认**把音频救回根目录**，另有红色选项「连文件一起删」。

### 第 3 步：把音频放进来

三种方式，任选：

| 方式 | 操作 | 适合场景 |
| --- | --- | --- |
| **拖拽** | 把文件从资源管理器直接拖进窗口 | 一次搬一批 |
| **添加音频** | 点右上角蓝色「添加音频」按钮选择文件 | 精确挑选 |
| **自己拷** | 用文件管理器把音频拷进对应仓库文件夹，再点顶栏「扫描」 | 已有大量音频 |

放进来的瞬间，程序会**自动拆开文件读取信息**：

- MP3 → ID3v2 标签（TIT2 标题 / TPE1 艺术家 / TALB 专辑 / TCON 流派）
- FLAC / OGG / Opus → Vorbis 评论
- M4A / MP4 / AAC → ilst 原子
- WAV / AIFF → INFO 块

**文件里没有标签也不要紧**，会从文件名反推。比如：

```
049 Joakim Karud - Classic (Vlog No Copyright Music).mp3
  → 创作者：Joakim Karud
  → 名称  ：Classic
  → 时长  ：8:58（从码率精确算出）

雨声_loop.wav
  → 名称：雨声 loop
  → 类型：环境音/氛围（从关键词猜）
```

### 第 4 步：补全信息

点音频行右侧的 **✎ 编辑**，可以填写或修改：

| 字段 | 说明 |
| --- | --- |
| 音频名称 | 自动识别后可改 |
| 创作者 | 歌手 / 音效作者 / 工作室 |
| 音频类型 | 配了常用候选值，点一下就填上 |
| 来源 | 素材站名、专辑、或个人自制 |
| **可商用范围** | 关系到能不能拿去用，见下方色标 |
| 专辑 / 标签 / 备注 | 附加信息，方便日后检索 |
| 所属仓库 | 直接在这里搬家，不用拖 |

### 第 5 步：粘贴一段文字，让它自动填

这是最省事的一招。点顶栏「**粘贴识别**」，把别人发给你的素材说明、网页上复制的一段介绍丢进去。

它认得这几种写法：

**① 带标签的**
```
音频名称：晨雾鸟鸣
创作者：陈默
音频类型：环境音
来源：耳聆网
可商用范围：CC0
```
（也认 `名称:` `曲名:` `Title:` `Artist:` `作者:` `类型:` `来源:` `授权:` 等中英文写法，冒号全角半角都行）

**② 光秃秃的一行**
```
周杰伦 - 晴天
```
→ 自动拆成 创作者「周杰伦」+ 名称「晴天」

**③ 一整段话**
```
这个是在 Pixabay 上找的 8bit 游戏音效，可以商用，作者是林深
```
→ 自动嗅探出 来源「Pixabay」、类型「游戏音效 / 8bit」、可商用范围「可商用」、创作者「林深」

识别结果会显示成可编辑的预览，**每个字段旁边有个小圆点表示把握高低**：实心＝高把握，空心＝推测，你确认无误再保存。

### 第 6 步：试听

- **悬停即播**：鼠标移到音频行最前面的波形区，播放键会从波形里浮出来，按下就播
- **行内进度条**：正在播放的那一行，底部有一条细进度条
- **底部播放器**：显示大波形进度条，**可以直接拖动定位**，还有上一条 / 下一条 / 循环 / 收藏
- **拖到侧栏仓库上**：音频行可以直接拖到左侧任意仓库，完成搬家

### ⌨️ 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` | 快退 5 秒 |
| `→` | 快进 5 秒 |
| `/` | 光标跳到搜索框 |
| `Esc` | 关闭弹窗 |

### 🎨 可商用范围色标

这个字段决定了音频能不能拿去用，所以用颜色区分：

| 颜色 | 含义 |
| --- | --- |
| 🟢 绿 | 可商用（含 CC0、完全免费商用） |
| 🟡 琥珀 | 可商用但需署名 |
| 🔴 红 | 仅限个人 / 非商用 |
| ⚪ 灰 | 待填写 |

> 音频行右侧和编辑面板都会显示这个色标，一眼扫过去就知道哪些能放心用。

### 🔍 搜索

顶栏搜索框会同时匹配 **名称 / 创作者 / 来源 / 类型 / 标签 / 备注**。也可以先点左侧某个仓库，再在仓库内搜索。

## 📦 数据存在哪里

```
你指定的储存路径/
├── .audiovault/
│   └── library.json      ← 所有文字信息（名称/创作者/来源/商用范围…）
├── 灵感仓库/
│   └── xxx.mp3
├── 常用音效/
│   └── yyy.wav
└── 没归类到仓库的音频.mp3
```

- 文字信息和音频**分离存放**，音频本身不被修改、不被转码
- `library.json` 是纯文本 JSON，用记事本就能打开，不锁进专有格式
- 想备份：整个文件夹复制走就行

## 常见问题

**Q：浏览器没自动打开？**
A：手动访问命令行窗口里显示的地址（默认 `http://127.0.0.1:8756/`）。

**Q：音频放不出来？**
A：浏览器原生支持 MP3 / WAV / M4A / OGG / FLAC 等常见格式。个别编码（如 APE、WMA）Chrome 系浏览器不支持，但元信息仍会正常登记。

**Q：扫描不到我的音频？**
A：点顶栏「扫描」按钮。支持格式见 `audiometa.py` 里的 `AUDIO_EXT`，也可以自行往里加扩展名。

**Q：波形没画出来？**
A：大于 32 MB 的文件会跳过波形计算（避免占用过多内存），播放和进度条不受影响。

**Q：能多人同时用吗？**
A：当前是单机本地版，服务只绑定 `127.0.0.1`，局域网内其他设备访问不到。

**Q：删掉仓库会不会连音频一起删？**
A：默认不会。删除时音频会被移回储存路径根目录；只有主动选择红色选项「连文件一起删」才会真正删除。

**Q：exe 的配置文件写在哪？**
A：写在 exe **所在的同一个文件夹**里（`config.json`），方便整个文件夹塞进 U 盘带走。若 exe 放在无写入权限的目录（如 `Program Files`），会自动退回 `%APPDATA%\AudioVault\`。
